# Contributing to AVARA

Thank you for your interest in contributing to AVARA!

AVARA is a weekend travel discovery and itinerary planning platform focused on scenic destinations and trekking experiences around Mysuru and Bengaluru, Karnataka.

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Install the project dependencies using the package manager and lockfile you intend to use.
4. Configure the required environment variables using `.env.example`.
5. Start the development server and explore the application.

Refer to the [README](README.md) for project information and setup instructions.

## How to Contribute

Contributions that improve the platform are welcome, including:

- Destination and trekking information.
- User interface and accessibility improvements.
- Bug fixes and performance improvements.
- Search and filtering functionality.
- Trip-planning enhancements.
- Documentation improvements.

## Development Guidelines

- Follow the existing project structure and coding conventions.
- Use TypeScript for new application code where appropriate.
- Build reusable components when they improve maintainability.
- Keep changes focused and clearly explain their purpose.
- Avoid introducing unnecessary dependencies.
- Never commit credentials, API keys, or other sensitive information.
- Do not introduce unverified destination information or misleading travel details.

## Submitting Changes

1. Create a branch for your changes.
2. Make and review your changes.
3. Test the affected functionality.
4. Ensure the application builds successfully.
5. Commit your changes with a descriptive message.
6. Open a pull request explaining what changed and why.

## Reporting Issues

When reporting an issue, include:

- A clear description of the problem.
- Steps to reproduce it.
- Expected and actual behaviour.
- Relevant screenshots or error messages, when available.

Never include passwords, database credentials, authentication secrets, or private user information in an issue.

## Code of Conduct

Be respectful, constructive, and considerate when communicating with maintainers and other contributors.

Thank you for helping improve AVARA!
